
# Dershane Otomasyonu

Java ve JavaFX kullanılarak geliştirilmiş, MySQL veritabanı ile desteklenen masaüstü dershane otomasyonu uygulamasıdır.

Uygulama; dershane içerisindeki öğrenci, öğretmen, sınıf, ders, sınav, not, devamsızlık ve ödeme işlemlerinin yönetilmesini amaçlamaktadır.

## Kullanılan Teknolojiler

- Java
- JavaFX
- MySQL
- JDBC

## Özellikler

- **Kullanıcı Yönetimi:** Yönetici ve öğretmen rolleri için kullanıcı girişi.
- **Öğrenci Yönetimi:** Öğrenci kayıt, listeleme, güncelleme ve silme işlemleri.
- **Öğretmen Yönetimi:** Öğretmen bilgilerinin yönetilmesi.
- **Sınıf Yönetimi:** Sınıf kayıt ve düzenleme işlemleri.
- **Ders Yönetimi:** Ders bilgilerinin yönetilmesi.
- **Sınav ve Not İşlemleri:** Öğrencilerin sınav ve not bilgilerinin takibi.
- **Devamsızlık Takibi:** Öğrenci devamsızlık bilgilerinin kaydedilmesi ve görüntülenmesi.
- **Ödeme Yönetimi:** Öğrenci ödeme ve taksit bilgilerinin takibi.

## Veritabanı

Uygulamada MySQL veritabanı kullanılmıştır. Java uygulaması ile veritabanı arasındaki bağlantı JDBC aracılığıyla sağlanmıştır.

## Projenin Amacı

Bu proje, Java programlama dili ile masaüstü uygulama geliştirme, JavaFX kullanarak grafiksel kullanıcı arayüzü oluşturma ve MySQL veritabanı işlemlerini uygulamalı olarak deneyimlemek amacıyla geliştirilmiştir.
